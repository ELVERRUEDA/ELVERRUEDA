## 🚀 Proyectos destacados

### 🪟 [Sistema de cortina automática + Programador de tareas IoT](https://github.com/ELVERRUEDA/cortina-automatica-esp32)
Sistema completo que integra hardware y software:
- **ESP32** controla un motor DC 12V via L298N
- **FastAPI + Firebase** gestiona las tareas programadas
- **React** como interfaz de usuario para programar tareas
- **n8n** automatiza notificaciones vía Telegram cuando una tarea se completa
> Stack: Python · FastAPI · React · Firebase · ESP32 · n8n · Docker

---

### 🌐 [API REST con FastAPI y Firebase](https://github.com/ELVERRUEDA/API-REST-FastAPI-firebase)

> Stack: Python · FastAPI · Firebase Admin SDK
